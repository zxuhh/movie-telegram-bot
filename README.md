# Movie Telegram Bot

Личный некоммерческий Telegram-бот для поиска и изучения информации о фильмах, сериалах и анимации.

> Проект находится на стадии подготовки. Функциональность и архитектура будут уточняться после изучения предоставленного примера бота.

## Планируемые возможности

- Поиск фильмов и сериалов по названию
- Карточки с описанием, постером, жанрами и датой выхода
- Фильтрация и подборки контента
- Избранное пользователя
- Сохранение пользовательских предпочтений
- Доступ к просмотру только через легальные источники, если такая функция будет реализована

## Технологии (предварительно)

- Python
- aiogram
- TMDB API — метаданные и изображения
- SQLite — локальное хранение данных

## Локальная конфигурация

Секреты будут храниться только в локальном файле `.env`, который не должен попадать в Git:

```env
BOT_TOKEN=your_telegram_bot_token
TMDB_API_KEY=your_tmdb_api_key
```

Не публикуйте токены, пароли, персональные данные или содержимое файла `.env`.
