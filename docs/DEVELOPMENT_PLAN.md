# План разработки

## Цель

Создать локально запускаемый Telegram-бот для личного некоммерческого использования. По пользовательскому опыту он должен быть похож на предоставленный пример `@smotrett1bot`, но иметь собственную реализацию и не показывать рекламу.

Этот документ — предварительный план. До написания основной логики необходимо пройти исходного бота и зафиксировать фактически доступные функции, меню и сценарии.

## Этап 1. Обследование примера

Зафиксировать:

- стартовое сообщение и главное меню;
- все кнопки, разделы и вложенные меню;
- поиск и поведение при отсутствии результатов;
- карточку фильма и карточку сериала;
- фильтры, жанры, сортировки и подборки;
- избранное и историю пользователя;
- настройки и команды;
- наличие видео, внешних ссылок и ограничения доступа.

Для каждого сценария подготовить скриншоты и пошаговое описание. Не предполагать функции, которые не удалось проверить.

## Этап 2. Спецификация и архитектура

После обследования:

- согласовать список функций первой версии;
- описать пользовательские сценарии и состояния диалогов;
- выбрать структуру модулей;
- определить схему SQLite;
- определить необходимые API и источники данных;
- зафиксировать требования к обработке ошибок и логированию.

Предварительный стек: Python, aiogram, SQLite и TMDB API для метаданных и изображений. Окончательный выбор подтвердить после анализа функций.

## Этап 3. Базовый каркас

- конфигурация через переменные окружения;
- загрузка и проверка настроек;
- инициализация бота и диспетчера;
- подключение SQLite;
- логирование;
- команда `/start` и базовая навигация.

## Этап 4. Каталог и поиск

- клиент TMDB API;
- поиск фильмов и сериалов;
- карточки контента;
- жанры, даты, рейтинги и постеры;
- пагинация и обработка пустых результатов.

Не хранить и не распространять нелицензионные копии фильмов или сериалов.

## Этап 5. Пользовательские функции

Реализовать только подтверждённые при обследовании сценарии:

- избранное;
- история запросов;
- фильтры;
- подборки;
- пользовательские настройки.

## Этап 6. Тестирование

Проверить:

- все команды и кнопки;
- корректную работу с ошибочными и пустыми запросами;
- тайм-ауты и ограничения внешнего API;
- сохранение данных после перезапуска;
- отсутствие утечки токенов в логах;
- повторные нажатия и некорректные состояния диалога.

## Этап 7. Локальный запуск

Подготовить инструкции для Windows:

- создание виртуального окружения;
- установка зависимостей;
- настройка локального `.env`;
- запуск и остановка бота;
- резервное копирование локальной базы.

## Безопасность

- Реальные `.env`, токены, ключи API и базы с персональными данными не коммитить.
- Использовать `.env.example` только с фиктивными значениями.
- При случайной публикации секрета немедленно отозвать и заменить его.
- Не обходить ограничения сторонних сервисов.

## Атрибуция TMDB

Если используются данные или изображения TMDB, добавить требуемое TMDB attribution notice и логотип в интерфейс приложения в соответствии с действующими требованиями TMDB. Само использование API не означает одобрения или сертификации проекта TMDB.

## Критерии готовности первой версии

- бот запускается локально на Windows по инструкции;
- основные согласованные сценарии работают;
- ошибки внешнего API обрабатываются;
- данные избранного сохраняются;
- секреты отсутствуют в репозитории;
- реклама отсутствует;
- атрибуция TMDB добавлена, если используется TMDB.
